# 🏋️ Gym SDR Prototype | Takayama AI

A white-label AI Sales Development Representative (SDR) designed for fitness centers and gyms to automate lead capture, handle customer support, and drive trial bookings 24/7.

## 📌 The Problem
Gyms and fitness centers receive high volumes of repetitive inquiries (class times, pricing, pool hours) across social media and website chats. Human staff cannot be available 24/7 to answer these instantly, leading to dropped leads and lost memberships. 

## 💡 The Solution
This intelligent digital concierge acts as a frontline team member. It instantly answers facility questions using a custom knowledge base and employs a low-pressure, consultative sales framework to convert casual browsers into booked facility tours and trial memberships.

## 🧠 Core Agent Logic
Unlike basic chatbots that spam users with links, this SDR is programmed with advanced conversational psychology:

*   **The Turn-Based Sales Engine:** The bot is strictly forbidden from pitching a trial in its first response. It must first provide value (e.g., answering a question about yoga class times) before unlocking its "soft-sell" promotional offer.
*   **The Dual Pivot System:** The AI automatically detects user intent. If an existing member asks about canceling a class, it fast-tracks them to the support portal. If a new user asks about pricing, it slows down and guides them through a lead-capture flow.
*   **Zero-Pressure Lead Capture:** The bot qualifies the user's fitness goals (e.g., weight loss, hypertrophy, swim lessons) before asking for contact details, ensuring the front desk receives highly qualified, context-rich leads.

## ⚙️ Tech Stack
*   **Conversational AI:** Google Dialogflow CX
*   **Logic Framework:** Phased Response Protocol & Anti-Repeat Logic
*   **Lead Routing:** Webhook integration for CRM/Google Sheets export (Simulation Mode enabled for this repository).
